# Zorykai Daily alpha.12

Variante visual com o mesmo núcleo e correções do alpha.12: Básica com ID caixa_inicial_rara (compatível com pendências antigas inicial_rara), chat após confirmação de entrega, e perfil opcional com chances de bônus reduzidas para um quarto. As demais chaves do Daily e Playtime coincidem com a lista enviada do servidor.

Instale somente um JAR Daily. Para aplicar as chances menores, faça backup e substitua somente config/shirokai-daily/rewards.json pelo arquivo em ../v0.1.0-alpha.12/rewards.json (ou use rewards-update-alpha.12.zip da mesma pasta). Não apague dados. Retente chaves anteriores em Entregas pendentes.

Nomes visuais Zorykai preservados, prefixo ✦ ZORYKAI branco e negrito, corpo cinza sem negrito. IDs, comandos e permissões permanecem shirokai. 99 testes e build Fabric passaram; sem validação funcional dentro do servidor Minecraft.
